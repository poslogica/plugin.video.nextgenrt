# Assets Required

This plugin requires the following asset files:

## Required Files

1. **icon.png** - Plugin icon (256x256 or 512x512 pixels recommended)
2. **fanart.jpg** - Background fanart image (1280x720 or 1920x1080 pixels recommended)

## Where to Place

Place these files in the root of the `plugin.video.nextgenrtfilms` directory:
- `plugin.video.nextgenrtfilms/icon.png`
- `plugin.video.nextgenrtfilms/fanart.jpg`

## Suggestions

You can:
- Create custom RT Films themed graphics
- Use screenshots from RT Films website
- Copy and modify assets from the other RT plugins as a starting point

Until these assets are added, the plugin will work but won't have proper icon/fanart display in Kodi.
